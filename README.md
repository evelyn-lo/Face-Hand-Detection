# Face Hand Detection, Googly Eyes Filters, and Hand Gesture Identification

This project applies googly eyes filter on detected faces in the webcam and recognizes hand gesture, such as rock, paper, and scissor, using Python, OpenCV, and MediaPipe. It features three main classes: 1. faceDetection with facial landmarking techniques and googly eyes placement, 2. HandDetector for hand detection and 3. Hand for identifying gestures (rock, paper, scissors) with CNN.
