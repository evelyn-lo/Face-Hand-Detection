# Face Hand Detection, Googly Eyes Filters, and Hand Gesture Identification

This project implements a real-time googly eyes filter and hand gesture recognition using Python, OpenCV, and MediaPipe. It features three main classes: 1. faceDetection for facial landmark detection and googly eyes placement, 2. HandDetector for hand detection and landmarking, and 3. Hand for identifying gestures (rock, paper, scissors) with a CNN.
